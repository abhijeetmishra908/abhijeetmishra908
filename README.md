## Projects

### [Car Price Prediction](https://github.com/abhijeetmishra908/Car-prediction)
Random Forest model with preprocessing and feature engineering, deployed as a Streamlit app for real-time car price category prediction.

### [House Price Prediction](https://github.com/abhijeetmishra908/House-Price-Prediction)
XGBoost pipeline with missing-value handling and feature scaling, deployed as an interactive Streamlit app.

### [Kidney Disease Prediction](https://github.com/abhijeetmishra908/Health-care)
XGBoost healthcare model with feature selection and preprocessing, deployed as a Streamlit prediction interface.

### [Vrinda Store Sales Analysis](https://github.com/abhijeetmishra908/vrinda-store-sales-analysis-excel-dashboard)
Interactive Excel dashboard with PivotTables, PivotCharts, and Slicers — monthly sales and orders, customer demographics, state-wise sales, and channels including Amazon, Flipkart, Myntra, Meesho, Nalli, and Ajio.

### [Email Spam Detection](https://github.com/abhijeetmishra908/NLP_Email)
Spam/Ham text classification with a Bag-of-Words vectorizer, with a FastAPI backend and HTML/CSS/JS frontend for real-time prediction.

### [Loan Default Prediction](https://github.com/abhijeetmishra908/Loan-Default-Prediction)
LightGBM model on Home Credit data (307,511 rows, 122 columns), with CSV upload, automatic preprocessing, and downloadable predictions via Streamlit.

### [BigBasket Product Rating Prediction](https://github.com/abhijeetmishra908/Big-Basket-Products)
Predicts highly rated (≥ 4.0) products from price and sub-category — around 27,000 products, tuned XGBoost F1 0.70, deployed with Streamlit.

### Currently Building: Twitter / X Sentiment — RAG
NLP pipeline analysing Twitter/X sentiment with a retrieval-augmented generation layer for grounded, context-aware querying. In progress — almost complete, not yet uploaded to GitHub, so no link is shown until it is live.
